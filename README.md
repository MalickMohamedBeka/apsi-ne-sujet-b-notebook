# Notebook bonus : injection SQL dans les paramètres HTTP

Notebook du bonus du sujet B (étude de cas MOVEit Transfer et CL0P), projet final IA Cyber, APSI-NE, Programme Excellence.

Il compare trois détecteurs sur un jeu public (HttpParamsDataset) : des règles simples, une régression logistique et une Isolation Forest entraînée sans attaque. Il termine par un test d'évasion simple. Le rapport PDF en donne les résultats (annexe B) et le code (annexe C).

Fichiers :

- `MOHAMED-BEKA_Malick_SujetB_bonus.ipynb` : le notebook, exécuté de bout en bout
- `MOHAMED-BEKA_Malick_SujetB_bonus.html` : son export, lisible sans Jupyter
- `requirements.txt` : versions des bibliothèques

Pour le relancer : `pip install -r requirements.txt`, puis ouvrir le notebook et choisir « Restart & Run All ». Il télécharge lui-même le jeu de données depuis https://github.com/Morzeux/HttpParamsDataset, qui n'est donc pas redistribué ici.
